# 真机平台与打包链路验证清单（Twikoo 2.0）

> 用途：附录 B.3「11 种部署形态」+ 4 个特别项的**人工操作与结果回收表**。
> 由维护者按表逐项执行并回填；**任一项失败不得跳过**——在「回填」列写明失败现象，
> 并在末尾「失败登记」区登记修复任务。
>
> 已由脚本自动核对的项（§4）无需人工重复；标 **【延后】** 的项依赖首发或平台账号。

## 1. 用法与判定标准

- 执行顺序建议：先 §4 自动项（本地，秒级）→ 再 §2 有账号的平台 → 最后 §3 特别项。
- **判定标准**：每形态都必须能完成「**部署 → 打开页面 → 评论列表渲染 → 发一条评论 → 管理员登录并读配置**」
  这五步，除非该项明确标注了裁剪范围（如 EO 的邮件受限）。
- 回填方式：把 `[ ]` 改成 `[x]`，并在「证据/备注」列写：执行时间、版本（`twikoo@2.0.0-beta.1`）、
  观察到的异常、截图或日志路径。
- 若某平台无法访问（无账号/区域限制），在备注写「不可达原因」并登记到 §6，**不要**留空。

## 6. 已知缺口与延后项（不得静默通过）

| 项                                                  | 现象（实测）                                                                                                                                                                                                                                                                   | 处置                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **pkg SEA 产物缺少重依赖**                          | `TWIKOO_PKG_BUNDLE_ONLY=1 pnpm --filter twikoo-pkg build:exe` 产物 `build/index.js`（1.70 MB）中：`xhr-sync-worker` 与 `ip2region.db` 两个插件的字符串替换**命中 0 次**；jsdom / dompurify / nodemailer / @imaegoo/node-ip2region 均**未被内联**（仅剩字符串形式的 specifier） | 根因：2.0 的重依赖经**变量间接的 `await import(specifier)`** 惰性加载（D-2 依赖外部化），打包器无法静态解析。**修复方向**：在 pkg 入口静态 import 全部重依赖并经 `setLibImporter`/`setCustomLibs` 注入（等价 1.x 打包结果）。登记于 `.omo/evidence/deferred-github-verifications.md`（宿主 Node ≥ 25.7 才能生成 SEA 产物做最终验证） |
| Docker / HF Space 平台实测                          | 本机无 Docker、无 HF 账号                                                                                                                                                                                                                                                      | 延后到正式版发布后由 `publish-docker` 产物 + 平台操作回填                                                                                                                                                                                                                                                                            |
| 5 个云平台（CloudBase/Vercel/Netlify/AWS/Deta）真机 | 需要各平台账号与凭据（R-5/R-14 要求至少 vercel/self-hosted/cloudbase 真机）                                                                                                                                                                                                    | 延后；本清单 §2 已给出可执行步骤与判定标准                                                                                                                                                                                                                                                                                           |
| 邮件 / 推送真实投递                                 | 需要真实 SMTP 与 pushoo token                                                                                                                                                                                                                                                  | 延后（人工）                                                                                                                                                                                                                                                                                                                         |
